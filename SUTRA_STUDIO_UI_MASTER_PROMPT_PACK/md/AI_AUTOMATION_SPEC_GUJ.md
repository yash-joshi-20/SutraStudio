## ૪. Meta Ads Manager ઓટોમેશન: વિગતવાર કાર્યપદ્ધતિ

### ૧. ફેસબુક અને ઇન્સ્ટાગ્રામ પેજ કનેક્ટ કરવાની રીત:
- **વિકલ્પ ૧ (ક્લાયન્ટનું પોતાનું પેજ)**: ક્લાયન્ટ પોતાના ડેશબોર્ડમાં "Connect Facebook" પર ક્લિક કરશે -> Meta OAuth પોપઅપમાં `pages_manage_ads` અને `ads_management` મંજૂર કરશે -> ક્લાયન્ટના Page ID અને Ad Account ID સિસ્ટમ સાથે કનેક્ટ થશે.
- **વિકલ્પ ૨ (એજન્સી પેજ)**: જો ક્લાયન્ટ પાસે પેજ ન હોય, તો સિસ્ટમ આપમેળે ક્લાયન્ટના બ્રાન્ડ નામનું પેજ એજન્સી પાર્ટનર એકાઉન્ટ હેઠળ સેટઅપ કરશે.

### ૨. ટાર્ગેટિંગ અને બજેટ સેટઅપ (AI ઓટોમેટેડ):
- AI ક્લાયન્ટના બિઝનેસ મુજબ ઓડિયન્સ ઇન્ટરેસ્ટ્સ પસંદ કરશે (દા.ત. ઇન્ટિરિયર ડિઝાઇન માટે: Architectural Digest, Luxury Home Renovation, ૨૮ થી ૫૫ વર્ષ, મેટ્રો શહેરો).
- ક્લાયન્ટે પસંદ કરેલા પ્લાન મુજબ દૈનિક બજેટ (Daily Budget Cap) ફાળવશે.

### ૩. ક્રિએટિવ અપલોડ અને એડ લોન્ચ:
- મંજૂર થયેલા 1:1, 9:16 બેનર્સ અને વિડિયો રીલ્સ Meta Ad Library માં જશે.
- AI દ્વારા તૈયાર કરેલ પ્રાઇમરી ટેક્સ્ટ, હેડલાઇન અને વેબસાઇટ ટ્રેકિંગ લિંક (`utm_source=meta_ads`) આપોઆપ જોડાઈને એડ લાઈવ થશે.

### ૪. શું AI થી થશે અને શું મેન્યુઅલ રહેશે?
- **AI થી થશે**: ક્રિએટિવ સાઇઝિંગ, કોપીરાઇટિંગ, ઓડિયન્સ મેપિંગ, UTM ટ્રેકિંગ અને કલાકે-કલાકે પરિણામોનું મોનિટરિંગ (Clicks, CTR, Leads).
- **મેન્યુઅલ રહેશે**: ક્લાયન્ટનું બજેટ વધારે ખર્ચાઈ ન જાય તે માટે એડમિન માત્ર એકવાર ફાઇનલ બજેટ કન્ફર્મ કરી "Active" કરશે.

## ૬. AI વોટરમાર્ક રીમુવલ અને ક્લાયન્ટનો ઓરિજિનલ લોગો લગાવવાની રીત

જ્યારે AI મોડલ્સ ઈમેજ કે વિડિયો બનાવે છે, ત્યારે તેમાં ડિફોલ્ટ લોગો કે વોટરમાર્ક ન આવે તે માટે આપણી સિસ્ટમ **ઓટોમેટેડ ક્લાઉડ કમ્પોઝીટર** વાપરે છે:

1. **ઈમેજ અને બેનર્સ માટે (Node.js Sharp કમ્પોઝીટર)**:
   - **પગલું ૧**: AI પ્રોમ્પ્ટમાં નેગેટિવ પ્રોમ્પ્ટ (`watermark, logo, text, branding`) આપી ક્લીન 8K બેકગ્રાઉન્ડ જનરેટ થાય છે.
   - **પગલું ૨**: Node.js `sharp` લાયબ્રેરી દ્વારા ક્લાયન્ટનો ઓરિજિનલ SVG/PNG લોગો ડાબી કે વચ્ચેની બાજુએ સુંદર ડ્રોપ-શેડો સાથે બેસાડવામાં આવે છે.
   - **પગલું ૩**: હેડલાઇન ટેક્સ્ટ અને કોલ-ટુ-એક્શન બટન ("Book Now", "Get Quote") ઓવરલે થાય છે.
   - **પગલું ૪**: પ્રીવ્યૂ માટે વોટરમાર્કવાળી ફાઈલ દેખાય છે અને મંજૂરી પછી **૪K લોસલેસ ક્લીન PNG** ડાઉનલોડ કરવા મળે છે.

2. **વિડિયો રીલ્સ માટે (FFmpeg ક્લાઉડ કમ્પોઝીટર)**:
   ```bash
   # FFmpeg કમાન્ડ: વિડિયોને 1080x1920 માં ક્રોપ કરી ક્લાયન્ટનો લોગો અને કેપ્શન્સ બેસાડશે
   ffmpeg -i raw_video.mp4 -i client_logo.png -filter_complex \
   "[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,eq=contrast=1.1:saturation=1.15[bg]; \
    [1:v]scale=180:-1[logo]; \
    [bg][logo]overlay=W-w-50:50[v]" \
   -map "[v]" -map 0:a? -c:v libx264 -crf 18 -preset fast output_master_reel.mp4
   ```
