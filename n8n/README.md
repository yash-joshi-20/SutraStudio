# Sutra Studio — Production n8n Automation Engine

This directory contains the production-ready, fully rebranded n8n workflow pipelines for **Sutra Studio**. Every pipeline adheres strictly to the studio's security directives, light-theme ivory brand aesthetics, administrative review gates, and idempotent execution guards.

## 📁 Workflows Inventory

| File | Workflow Name | Trigger | Core Responsibility |
| :--- | :--- | :--- | :--- |
| [`W1_order_fulfillment_router.json`](./W1_order_fulfillment_router.json) | **W1 Order Fulfillment Router** | Webhook (`POST /W1_order_fulfillment_router`) | Idempotent order intake upon verified payment. Responds 200 immediately, queries `/api/n8n/orders`, routes AI-draft services vs Human-production tasks, uploads outputs to Drive `02 Drafts`, and reports `draft_ready` to Sutra App for **Admin Review**. |
| [`W2_approval_and_publish.json`](./W2_approval_and_publish.json) | **W2 Post-Approval & Publish Pipeline** | Webhook (`POST /W2_approval_and_publish`) | Triggered ONLY after client approves deliverables AND opts into social publishing. Executes official Meta Graph 2-step Instagram flow (container creation &rarr; status polling until `FINISHED` &rarr; `media_publish`) + Facebook Page feed publish. |
| [`W3_monthly_plan_content.json`](./W3_monthly_plan_content.json) | **W3 Monthly Plan Content Generator** | Cron Schedule (`0 9 * * *`) | Queries `/api/n8n/subscriptions` for active, non-expired, non-closed monthly retainers. Respects 3-day trial rules and package quotas, synthesizes weekly content matrix via Gemini AI, and vaults drafts for Admin review. |
| [`W4_error_handler.json`](./W4_error_handler.json) | **W4 Global Error Handler** | `Error Trigger` | Catches unhandled node failures across all workflows, synchronizes failure state (`generation_failed`) on the order in Firebase ledger, and alerts Studio Admin with an instant retry link. |
| [`W5_agency_daily_autopost.json`](./W5_agency_daily_autopost.json) | **W5 Agency Daily Autoposter** | Cron Schedule (`0 10 * * *`) | Generates Sutra Studio brand showcase imagery and editorial copy. Defaults to **Draft-Mode** in the Studio Admin Console (no direct unapproved publishing) and uses a Merge node for a single audit log entry. |

## 🛠️ Audit Summary & Bugs Fixed

The legacy draft pipelines in `SUTRA_STUDIO_UI_MASTER_PROMPT_PACK/md/` contained critical flaws that have now been resolved:

1. **Invalid JSON Expressions**: Fixed syntax errors where request bodies were concatenated with `" + ... + "` and unquoted `$now`. All bodies are now valid n8n expressions using `{{ $json... }}` and native JSON.
2. **Webhook Response Mode Mismatch**: Added `Respond to Webhook` nodes immediately after webhook intake nodes configured with `responseMode: "responseNode"`, ensuring HTTP 200 is returned within milliseconds.
3. **Ghost Node Referencing**: Eliminated broken `$('node').first()` calls on nodes that were bypassed by conditional branching.
4. **Real Image Generation**: Replaced dummy Pollinations string building with official Stable Diffusion XL / Gemini Imagen generation API calls.
5. **Kling AI Video Polling & Auth**: Removed malformed header `"Bearer ={{...}}"` and fake stock-video fallbacks. Implemented authentic Bearer token authorization and asynchronous polling (`/v1/videos/text2video/{task_id}`) until render completion.
6. **ElevenLabs Audio Persistence**: Voiceover files generated by ElevenLabs are now labeled and linked directly into the order's Google Drive `02 Drafts` folder.
7. **Duplicate Branch Execution**: Added native n8n `Merge` nodes to combine concurrent branches before webhook callbacks and audit logging.
8. **Security & Authentication**: Eliminated unauthenticated `localhost:3000` URLs. All endpoints are protected by `x-sutra-secret` header verification.
9. **Admin Review Gate**: Output deliverables are routed strictly to Studio Admin review first (`status: "draft_ready"`); unverified AI drafts are **never** delivered directly to clients.
10. **Rebranding**: Removed all legacy demo brands (*Synapse Kinetic*, *Apex Luxe*, dummy emails, hardcoded IDs). Rebranded completely to **Sutra Studio**.

## 🌐 Next.js App Integration Endpoints

The Sutra Studio Next.js application exposes the following secured endpoints under `/api/n8n/*`:

### 1. `POST /api/n8n/dispatch`
Called when an order payment is confirmed or when an admin requests a retry.
- **Header**: `x-sutra-secret: <N8N_WEBHOOK_SECRET>`
- **Payload**:
  ```json
  {
    "workflowId": "W1_order_fulfillment_router",
    "orderId": "ord_001",
    "service": "Image Creation",
    "brief": "Luxury teak pavilion with brass accents",
    "driveFolderId": "drive_fld_sutra_001"
  }
  ```

### 2. `POST /api/n8n/webhook`
Called by n8n when drafts are vaulted, tasks are created, or execution fails.
- **Header**: `x-sutra-secret: <N8N_WEBHOOK_SECRET>`
- **Payload (`draft_ready`)**:
  ```json
  {
    "orderId": "ord_001",
    "runId": "sutra_run_1727950000",
    "workflowId": "W1_order_fulfillment_router",
    "status": "draft_ready",
    "deliverableUrl": "https://drive.google.com/...",
    "filename": "Image Creation_Draft_v1.zip",
    "notes": "Concept draft vaulted in 02 Drafts."
  }
  ```

### 3. `GET /api/n8n/orders?orderId=...`
Allows n8n W1 to load full brief, attachments, and Google Drive subfolder mappings.

### 4. `GET /api/n8n/subscriptions`
Allows n8n W3 to query active, non-expired retainer subscriptions.

### 5. `POST /api/n8n/retry`
Admin action to re-trigger an order pipeline with maximum retry limit enforcement (capped at 2 retries).

## 🧪 Testing with Mock / Test Credentials

To verify the pipeline locally without making paid external API calls:

1. Send a test dispatch to the local Next.js instance:
   ```bash
   curl -X POST http://localhost:3000/api/n8n/dispatch \
     -H "Content-Type: application/json" \
     -d '{"workflowId": "W1_order_fulfillment_router", "orderId": "ord_001", "isMockTest": true}'
   ```
2. Verify that the order status transitions to `draft_delivered` ("Draft Vaulted — Awaiting Admin Review").
3. Inspect `/admin/orders?id=ord_001` in the browser — confirm the Admin Review banner appears and that the client has not received unapproved drafts.
4. Test W4 error handler by dispatching with an invalid payload or testing `/api/n8n/webhook` with `status: "generation_failed"`. Confirm the admin alert notification is recorded.
