## 1. Observable Presets Catalog

Extracted from audit of project showreels, UI demonstrations, motion graphics, and architectural 3D workflows:

### 1. `preset-edu-kinetic-explainer` (Kinetic Tech Explainer Reel)
- **Category:** `educational_reels` | **Aspect Ratio:** 9:16 | **Duration:** 20–35s
- **Visual Style:** Warm ivory canvas (`#FAF9F5`), charcoal typography, warm brass highlight boxes.
- **Scene Progression:** Hook (0-3s) → Problem vs Solution (3-10s) → 3-Step Walkthrough (10-22s) → Outcome CTA (22-30s).
- **Camera Movement:** Static frame with simulated 1.15x punch-in on key statements; zero camera shake.
- **Editing Techniques:** Jump cuts, synchronized karaoke subtitles, split screen Before vs After.

### 2. `preset-screen-ui-walkthrough` (Precision UI / Product Walkthrough)
- **Category:** `screen_ui_demo` | **Aspect Ratio:** 16:9 | **Duration:** 30–60s
- **Visual Style:** Authentic Next.js / Figma screen capture in browser bezel with frosted glass backdrop.
- **Scene Progression:** Full Viewport (0-4s) → Zoom to Action (4-15s) → Live Execution (15-30s) → Delivery Receipt (30-40s).
- **Camera Movement:** Keyframed 35mm pan/zoom following cursor coordinates; 60fps smooth easing.
- **Editing Techniques:** Cursor radial halo (`#A98B5733`), 16px background blur during zoom, coordinate tooltips.

### 3. `preset-marketing-luxury-atelier` (Luxury Creative Atelier Commercial)
- **Category:** `marketing_commercial` | **Aspect Ratio:** 16:9 | **Duration:** 25–45s
- **Visual Style:** Warm ivory minimalism, soft golden hour lighting, tactile materials (travertine, hand-made paper).
- **Scene Progression:** Macro Texture (0-4s) → Art & Code Juxtaposition (4-12s) → Client Showcase (12-22s) → Sutra Emblem (22-30s).
- **Camera Movement:** Slow deliberate dolly-in and lateral slider movement; 48fps slow-motion feel.

### 4. `preset-cinematic-architectural` (Cinematic Drone & Architectural Fly-Through)
- **Category:** `cinematic_video` | **Aspect Ratio:** 16:9 | **Duration:** 20–40s
- **Visual Style:** Volumetric daylight god rays, warm stone colonnades, indoor-outdoor seamless glide.
- **Scene Progression:** High Aerial (0-5s) → Courtyard Glide (5-14s) → Hero Courtyard Push (14-22s) → Twilight Time-Lapse (22-28s).

### 5. `preset-interior-3d-turntable` (Photorealistic 3D Spatial & Product Turntable)
- **Category:** `interior_3d_360` | **Aspect Ratio:** 1:1 / 2:1 Equirectangular | **Duration:** 15–30s
- **Visual Style:** Studio cyclorama lighting, physically-based materials (PBR), brass rim lighting.
- **Scene Progression:** 360 Turntable Orbit (0-6s) → Material Macro (6-15s) → Exploded Layout (15-25s) → 360 Pano (25-30s).
