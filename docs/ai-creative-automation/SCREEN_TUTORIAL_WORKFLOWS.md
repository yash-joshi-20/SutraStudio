## 1. Operating Rules for Software Demonstrations

1. **Authentic Screen Content Only:**
   - Real Next.js routes (`/admin`, `/orders`, `/media`, `/chat`) are recorded.
   - Fake browser controls, fictional data, and fabricated buttons are strictly prohibited.
2. **Lossless Capture & Pacing:**
   - 60fps desktop screen capture at 1920x1080 (16:9) or 1080x1920 (9:16 vertical crop).
   - Dynamic pan and zoom (1.3x to 1.5x) focusing on interactive click points.
3. **Cursor Tracking & Tooltip Annotations:**
   - Soft brass radial beacon (`#A98B5733`) following pointer path.
   - Floating tooltips anchored 24px above clicked elements explaining workflow actions.
4. **Privacy Protection:**
   - Automatic redaction of private API keys, user passwords, and customer phone numbers before rendering.
