## Root Cause Analysis

### Critical: Firestore not reachable (code 7)

**Most likely cause**: The Firestore database does not exist yet in the Firebase project, or the Cloud Firestore API is not enabled for the project `sutra-studio`.

**Evidence**: Auth SDK works (listUsers returns users), which proves the service account credentials are valid. Only Firestore is blocked. The Admin SDK bypasses security rules, so the PERMISSION_DENIED is at the API/database-existence level, not the security rules level.

**Fix**: 
1. Go to [Firebase Console](https://console.firebase.google.com/) → Project `sutra-studio`
2. Click **Firestore Database** in the left nav
3. Click **Create database** if it says "No database yet"
4. Choose **Production mode** and a region (e.g., `asia-south1`)
5. After creation, run `npm run check:auth` again — the FAIL should become PASS

**Impact of this issue**: All order creation, profile storage, and data persistence will fail silently with 500 errors. This is the most important thing to fix.
